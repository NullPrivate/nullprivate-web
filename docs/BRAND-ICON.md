# 宁屏品牌图标：N · 隐私之窗

## 设计意图

- 圆角方形代表屏幕与私密空间，以柔和轮廓表达家庭产品的亲近感。
- 连续的白色 N 对应 NullPrivate，斜向笔画将屏幕划成两个留白窗口，表达空间分隔与隐私边界。
- 延续品牌深青绿 `#0f766e`，搭配白色 `#ffffff`。使用纯色、粗笔画和圆端点，在小尺寸下保持清晰。

## 素材与复用

- 唯一矢量源：[public/favicon.svg](../public/favicon.svg)。导航、文档站与 favicon 共用此文件。
- 浏览器预览：启动开发服务后访问 `/brand/preview.html`，查看明暗背景和 16–128px 实际尺寸。
- 图标画布为 64 × 64；外轮廓圆角 18；N 笔画宽度 8，16px 显示时对应 2px。
- 推荐导航尺寸 32px，周围保留至少图标宽度 1/4 的空间。放大导出时保持正方形比例。
- 图文组合保留“宁屏”文字；相邻图标使用空 `alt`，首页链接提供完整名称。独立图片使用 `alt="宁屏"`。
- 两个品牌站点共享当前标志；图标不依赖字体、脚本或外部图像。

## 验收

在项目根目录运行：

```sh
npm run typecheck
npm run build:all
node --test scripts/test-brand-icon.mjs scripts/test-homepage.mjs
```

浏览器检查：首页、文档站、375px 窄屏、键盘焦点，以及明暗背景下的 16/32px 图标。标志为静态图形，适配减少动态效果的偏好。
