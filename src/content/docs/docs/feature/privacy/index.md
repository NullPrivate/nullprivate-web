## 隐私与广告的关系

广告商的收入主要来自广告转化。为提高转化率，平台需要：

1. 提高用户留存率
2. 投放个性化广告

这就需要大量收集用户隐私数据。平台通过以下方式规避法律限制：

- 复杂的用户协议
- 与合作伙伴交换数据
- 伪装的数据匿名化

## 隐私保护优先级

隐私保护比单纯去广告更重要：

- AdGuard中文区的跟踪拦截规则（>40万条）远多于广告规则（<10万条）
- 某些平台虽广告少，但通过隐私数据获取更多收益

## 平台的"贴心"背后

所谓的个性化推荐往往并非真正了解用户需求，而是平台的营销策略：

- "你喜欢这个"实际是"我想卖这个"
- 看似贴心的服务背后是持续的数据收集
