[list.adguardprivate.com](https://list.adguardprivate.com) 可以按应用生成防沉迷规则清单。本指南说明如何选择服务、获取直链，并将它保存到宁屏的“防沉迷”配置中。

> 防沉迷直链包含账号标识与已选服务信息。请勿将完整链接、登录令牌、浏览器 Cookie 或密码发布到公开页面。

## 1. 选择应用

1. 打开 [list.adguardprivate.com](https://list.adguardprivate.com)。
2. 使用搜索框查找目标应用。
3. 点击服务卡片完成选择；卡片会显示“已选择”。
4. 打开导航栏中的“名单生成器”。
5. 确认页面顶部的已选服务数量正确。

服务名称可能重复，建议通过服务域名确认条目。例如演示中的微博与 TikTok 分别选择 `www.weibo.com` 和 `www.tiktok.com`，而不是同名的其他条目。

## 2. 生成防沉迷直链

1. 在名单生成器中选择“防沉迷规则 (JSON)”。
2. 等待“生成的名单”出现包含 `blocked_services` 的 JSON。
3. 点击“获取链接”。
4. 登录名单站后，复制页面生成的完整直链。

请使用页面生成的链接，不要手动拼接 URL。若生成器显示“已选择 0 个服务”，请返回首页重新选择；选择状态保存在当前浏览器的本地存储中。

## 3. 导入宁屏

1. 打开宁屏管理页面，进入“过滤器”中的“防沉迷”。
2. 点击“显示配置源”。
3. 点击“添加URL”。
4. 粘贴名单站生成的防沉迷直链。
5. 点击配置源面板内的 `save`。
6. 等待服务列表刷新，再勾选需要阻止的应用。
7. 点击防沉迷页面的“保存”。

配置源保存后，服务列表会按新清单重新加载。请根据页面显示的服务名称进行勾选，不要依赖旧的内部 ID。

## 4. 验证结果

保存完成后刷新“防沉迷”页面，确认：

- 服务配置源中存在刚才的直链；
- 服务列表中出现目标应用；
- 目标应用保持勾选状态；
- 刷新页面后配置仍然存在。

若服务列表没有出现目标应用，先检查直链是否可以访问，再回到名单站确认已选服务和生成的名单内容。
