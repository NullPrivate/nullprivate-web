iOS 14以上版本支持原生Dns over HTTPS(DoH)和DNS over TLS(DoT)加密DNS, 您可以通过以下方法开启：

1.  打开自带浏览器Safari, 导航到私有服务后台, **设置指导**->**DNS 隐私**
2.  **下载配置文件**
3.  打开手机**设置**
4.  点击**通用**
5.  点击**VPN和设备管理**
6.  选中您的专用配置进行安装
