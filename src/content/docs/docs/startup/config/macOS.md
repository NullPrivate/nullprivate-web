macOS Big Sur 以上版本支持原生Dns over HTTPS(DoH)和DNS over TLS(DoT)加密DNS, 您可以通过以下方法开启：

1.  打开自带浏览器Safari, 导航到私有服务后台, **设置指导**->**DNS 隐私**
2.  **下载配置文件**
3.  打开**系统设置**
4.  打开**隐私与安全性**
5.  选中**描述文件**
6.  选中您的专用配置进行安装
