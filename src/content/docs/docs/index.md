# 欢迎来到宁屏的世界 - 您的私人网络安全卫士

**还在为无处不在的广告、烦人的弹窗和潜在的隐私泄露而烦恼吗？**

宁屏 (NullPrivate) 为您的所有联网设备提供一道坚不可摧的数字屏障。我们通过强大的加密 DNS 技术，在网络请求的源头就将广告、跟踪器和恶意网站拒之门外，还您一个清爽、高速、安全的互联网。

---

## 🚀 为什么选择宁屏？

我们相信，每个人都应享有纯净且安全的网络空间。

*   **广告去无踪**: 屏蔽视频、网页、App内的各类广告，享受沉浸式内容。
*   **隐私更安全**: 阻止第三方跟踪器收集您的上网习惯，保护个人隐私。
*   **上网防病毒**: 自动拦截钓鱼网站、恶意软件和诈骗信息，守护家庭网络安全。
*   **设置超简单**: 无需安装任何软件，在手机、电脑、路由器上原生设置即可，一劳永逸。
*   **全平台支持**: 无论是 Windows, macOS, iOS, Android 还是 Linux，我们都提供详尽的图文设置教程。
*   **家庭防沉迷**: 通过防沉迷功能，为孩子营造健康的网络环境，防止过度沉迷。

---

## 核心功能

### 🛡️ 免费服务

所有用户均可享受强大的基础防护功能：

*   **公网访问**: 全面支持 IPv4 和 IPv6 网络环境。
*   **广告屏蔽**: 拦截绝大多数广告来源。
*   **隐私保护**: 屏蔽已知的用户行为跟踪器。
*   **安全防护**: 远离钓鱼和诈骗网站，尤其适合为家中老人配置。
*   **家庭保护**: 基础的防沉迷功能，帮助管理家庭网络使用。

### ✨ 高级定制 (付费服务)

解锁更多个性化与精细化管理功能：

*   **上网行为分析**: 查看您网络中的设备访问了哪些网站，数据尽在掌握。
*   **防沉迷**: 一键屏蔽成人内容和游戏网站，为孩子营造健康的网络环境。
*   **自定义规则**: 完全控制您的网络，屏蔽特定 App、网站或游戏。
*   **内网穿透**: 自定义域名解析，轻松访问家中的 NAS 或服务器。
*   **多设备管理**: 通过客户端ID，区分并管理不同设备的上网策略与记录。
*   **防沉迷设置**: 精细化的时间管理和内容过滤，防止孩子过度使用网络。
