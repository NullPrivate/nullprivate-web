iOSデバイスで誤検知の問題が発生した場合、以下の2つの方法で元のDNS設定を復元できます。

## 方法1：DNS暗号化を一時的に無効化

この方法はDNS設定が原因かどうかを一時的にテストする場合に適しています：

1. `設定`アプリを開く
2. `一般` > `VPNとデバイス管理`に移動
3. `アクセス制限とプロキシ`セクションで`DNS`オプションを探す
4. `自動`を選択すると一時的にシステムデフォルト設定に復元されます

## 方法2：設定を完全に削除

DNS暗号化設定を完全に削除する場合：

1. `設定`アプリを開く
2. `一般` > `VPNとデバイス管理`に移動
3. `構成プロファイル`で`public.adguardprivate.com DoT`を探す
4. `プロファイルを削除`をクリックして確認

> NullPrivateを永久に使用しないと決めた場合、それは私たちのサービスが不快な体験をもたらしたことを意味します。ご迷惑をおかけし申し訳ございません。  
> パブリックサービスでは一般的なブロックルールを使用していますが、人的リソースの制限により、すべてのアプリの検知漏れや誤検知を把握することはできません。  
> 個別のニーズに合わせてルールをカスタマイズしたい場合は、プライベートサービスの購入をご検討ください。プライベートサービスは非常にコストパフォーマンスが高く、様々なニーズに対応する専用サービスを提供しています。
