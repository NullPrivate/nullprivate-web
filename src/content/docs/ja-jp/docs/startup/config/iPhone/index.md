iOS 14以降のバージョンではネイティブでDNS over HTTPS(DoH)とDNS over TLS(DoT)暗号化DNSをサポートしています。以下の方法で有効化できます：

1.  標準ブラウザSafariを開き、プライベートサービス管理画面に移動し、**設定ガイド**->**DNSプライバシー**
2.  **設定ファイルをダウンロード**
3.  スマートフォンの**設定**を開く
4.  **一般**をタップ
5.  **VPNとデバイス管理**をタップ
6.  専用設定を選択してインストール
