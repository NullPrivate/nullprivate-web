## Windows 11 21H2以降のバージョン

Windows 11 21H2以降では、ネイティブのDns over HTTPS(DoH)がサポートされています。以下の方法で有効にすることができます：

1. `設定`を開く
2. `ネットワークとインターネット`を開く
3. `イーサネット`を開く
4. `DNSサーバーの割り当て`を見つけ、`編集`をクリック
   1. `手動`を選択
   2. `優先DNSサーバー`のIPv4に`111.229.178.206`を入力
   <!-- IPv6アドレスは`2408:4005:3de:8500:4da1:169e:dc47:1707` -->
   3. DNS over HTTPS(DoH)の選択: オン(手動テンプレート)
   4. `DoHテンプレート`に`https://public.adguardprivate.com/dns-query`を入力
   5. **チェックしないでください**`失敗時に暗号化されていないリクエストを使用`
   6. 代替DNSサーバーには`223.5.5.5`(アリババクラウドのパブリックDNSサービス)を入力し、`DNS over HTTS`をオフにし、`失敗時に暗号化されていないリクエストを使用`にチェックを入れることができます。

> 無料版は現在IPv4のみ提供しています。IPv6を使用する場合は、有料のプライベートサービスを検討してください。

## Windows 10およびそれ以前のバージョン

Windows 10およびそれ以前のバージョンでは、ネイティブの暗号化DNSはサポートされていませんが、Chrome/EdgeやChromiumベースのブラウザを使用している場合、ブラウザ内で`DoH`暗号化DNSを設定できます。以下はChromeブラウザの設定方法です：

1. Chromeブラウザの`設定`を開く
1. `プライバシー、検索、サービス`を開く
1. `セキュリティ`までスクロール
1. `安全なDNSを使用してウェブサイトのネットワークアドレスを検索する方法を指定`を有効にする
1. `サービスプロバイダーを選択`に`https://public.adguardprivate.com/dns-query`を入力
