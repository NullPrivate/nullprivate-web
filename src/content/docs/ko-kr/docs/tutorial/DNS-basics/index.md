> 본질적으로 DNS 서비스는 신화사전과 같습니다. 사전을 조회함으로써 우리는 도메인 이름에 해당하는 IP 주소를 찾을 수 있습니다.

## DNS 소개

DNS(Domain Name System, 도메인 이름 시스템)는 인터넷의 기반 시설 중 하나로, 마치 신화사전처럼 사람이 읽기 쉬운 도메인 이름을 컴퓨터가 이해할 수 있는 IP 주소로 변환합니다.

![DNS 해석 원리](/images/docs-tutorial-DNS-basics-202501151801448.svg)

## DNS의 작동 원리

브라우저에 웹 주소를 입력할 때:

1. 브라우저는 먼저 로컬 캐시를 확인합니다
2. 찾지 못하면 DNS 서버에 쿼리를 시작합니다
3. DNS 서버는 해당 IP 주소를 반환합니다
4. 브라우저는 해당 IP 주소를 사용해 대상 웹사이트에 접속합니다

## 주요 개념

- **도메인 이름(Domain Name)**: 웹사이트의 읽기 쉬운 주소, 예: `www.nullprivate.com`
- **URL(Uniform Resource Locator)**: 프로토콜, 도메인 이름 및 경로를 포함한 완전한 웹 주소, 예: `https://www.nullprivate.com`
- **IP 주소**: 네트워크 장치의 숫자 식별자, 예: `1.1.1.1`
- **DNS 서버**: 도메인 이름 해석 서비스를 제공하는 컴퓨터
- **웹사이트 호스팅**: 웹사이트 파일을 서버에 저장하여 인터넷을 통해 접근할 수 있도록 하는 것
