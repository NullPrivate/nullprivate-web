## 동작 원리 개요

NullPrivate는 DNS 수준 차단으로 사용자의 네트워크 보안과 개인정보를 보호합니다. 이는 모든 도메인 요청을 스크리닝하는 지능형 게이트키퍼 역할을 합니다:

- ✅ 안전한 사이트: 정상 접속
- ❌ 광고 도메인: 차단
- ❌ 트래커: 차단
- ❌ 악성 사이트: 차단

## 주요 특징

1. **DNS 수준 차단**: 요청 발생 전에 차단하여 더 효율적
2. **플러그인 설치 불필요**: 네트워크 수준 보호로 모든 기기에서 효과적
3. **저자원 소모**: DNS 요청만 처리하여 기기 성능 영향 최소화
4. **전 기기 커버리지**: 한 번의 설정으로 모든 연결 기기 보호
