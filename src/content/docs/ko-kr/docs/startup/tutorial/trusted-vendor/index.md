유료 서비스 생성 시, 기본적으로 국내 빠른 업스트림 서비스를 사용합니다. 여기에는 Alibaba의 IPv4 및 IPv6, DoT 서비스가 포함됩니다.

일부 서비스 제공업체는 해외 웹사이트를 잘못된 IP 주소로 해석하여 접근 불가 문제를 일으킬 수 있습니다. 일반적인 증상은 브라우저에서 인증서 오류가 발생하는 것입니다.

해석 오류를 방지하려면 `Cloudflare`와 같은 업스트림 서비스 제공업체를 변경하여 `DoH` 또는 `DoT` 프로토콜을 사용하십시오. 이 경우 하이재킹을 방지하기 위해 해당 프로토콜을 사용 중인지 확인하세요.

동시에 국내 업스트림 서비스를 비활성화해야 합니다. 이들은 거리가 가깝고 속도가 빨라 AdGuard가 우선적으로 사용하기 때문입니다.

해당 서비스 IP 앞에 `#`을 추가하면 업스트림 서비스를 비활성화할 수 있습니다.

![해석 오류 방지](/images/docs-startup-tutorial-trusted-vendor-202501031710444.png)

설정 후 업스트림 서버가 사용 가능한지 확인하기 위해 `업스트림 테스트`를 수행하고, 사용 가능한 경우 `적용`하십시오.

![해석 오류 방지-적용](/images/docs-startup-tutorial-trusted-vendor-202501031711475.png)

그러나 해외 서비스만 사용하면 국내 앱의 접근 경험이 저하될 수 있습니다. 국내 앱은 일반적으로 해외용 해석을 특정 외부 서버로 설정하여 국내 접속 속도가 느릴 수 있기 때문입니다.

일반적으로 사용하는 서비스의 해석 오류만 방지하려면, 해석 오류가 발생하는 도메인에 특정 해석 주소를 지정할 수 있습니다. 지정되지 않은 도메인은 기본 국내 업스트림 서비스를 계속 사용합니다.

AdGuard 콘솔에서 `설정` -> `DNS 설정` -> `업스트림 DNS 서버`를 선택하고, 해석 오류가 발생하는 도메인을 `[/example1.com/example2.com/]tls://1.0.0.1` 형식으로 `사용자 정의 DNS 서버`에 추가한 후 `설정 저장`을 클릭하십시오.

![업스트림 서버 설정](/images/docs-startup-tutorial-trusted-vendor-202411261430607.png)

![업스트림 서버 설정](/images/docs-startup-tutorial-trusted-vendor-202501031712566.png)

`public2.adguardprivate.svc.cluster.local`은 우리가 내부적으로 제공하는 해석 오류 없는 해석 서비스입니다. 업스트림으로 *Cloudflare*를 선택하여 사용자가 직접 해외 업스트림을 지정하는 것보다 더 빠른 해석 속도를 제공합니다. 대신 도메인 해석 업데이트 시 약간의 지연이 발생할 수 있습니다. 전문적인 요구사항이 없는 사용자는 모두 우리가 제공하는 해석 오류 없는 해석 서비스를 사용할 수 있습니다.

*Cloudflare* 또는 *Google*의 외부 해석 주소를 사용하려면 IP를 사용하여 DoT/DoH를 지정해야 합니다. 다음을 참조하십시오:

```
#tls://1.1.1.1
tls://1.0.0.1
tls://[2606:4700:4700::1111]
tls://[2606:4700:4700::1001]
tls://[2606:4700:4700::64]
tls://[2606:4700:4700::6400]
https://1.1.1.1/dns-query
https://1.0.0.1/dns-query
https://[2606:4700:4700::1111]/dns-query
https://[2606:4700:4700::1001]/dns-query
#tls://8.8.8.8
#tls://8.8.4.4
tls://[2001:4860:4860::8888]
tls://[2001:4860:4860::8844]
tls://[2001:4860:4860::64]
tls://[2001:4860:4860::6464]
#https://8.8.8.8/dns-query
#https://8.8.4.4/dns-query
#https://[2001:4860:4860::8888]/dns-query
https://[2001:4860:4860::8844]/dns-query
```

> `#`으로 주석 처리된 주소는 현재 방화벽에 의해 차단되어 사용할 수 없음을 의미합니다.

**본 사이트는 IPv6을 완벽하게 지원하며, 이것이 우리의 장점 중 하나입니다**. IPv6 주소의 업스트림을 사용하여 더 안정적인 해석 속도를 얻을 수 있습니다.
