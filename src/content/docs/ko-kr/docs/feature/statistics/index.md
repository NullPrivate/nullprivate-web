# DNS 쿼리 통계

AdGuard 개인 서비스는 네트워크 사용 현황을 더 잘 이해할 수 있도록 상세한 DNS 쿼리 통계 분석을 제공합니다.

## 요청 도메인 순위

![요청 도메인 순위](/images/docs-feature-statistics-image-1.png)

통계 내용:

- 도메인 접근 빈도 통계
- 각 도메인의 요청 횟수
- 시간대별 추세 확인
- 검색 및 필터링 지원

## 차단 기록 분석

![차단 도메인 순위](/images/docs-feature-statistics-image-2.png)

상세 내용:

- 차단된 도메인 목록
- 차단 규칙 매칭 상세 정보
- 차단 사유 설명
- 차단 시간 기록

## 데이터 활용

통계 데이터는 다음과 같은 목적으로 활용 가능:

- 잠재적 보안 위협 발견
- 광고 필터링 규칙 최적화
- 네트워크 사용 습관 분석
- 네트워크 접근 정책 조정
