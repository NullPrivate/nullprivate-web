## 전체 접속 요청 로그

![요청 로그](/images/docs-feature-query-image.png)

접속 요청 로그는 다음과 같은 상세 정보를 제공합니다:

- 시간: 요청이 발생한 정확한 시간
- 클라이언트: 요청을 시작한 장치의 IP 주소
- 요청 대상: 접속한 도메인 또는 IP 주소
- 응답 상태: 요청 처리 결과
- 필터 규칙: 트리거된 필터 규칙 (해당되는 경우)

검색창을 사용하여 도메인, IP 또는 규칙 이름으로 로그를 필터링할 수 있습니다. 로그는 기본적으로 3일 동안 보관됩니다.

## 요청 도메인 순위

![요청 도메인 순위](/images/docs-feature-query-image-1.png)

도메인 접속 통계는 다음을 보여줍니다:

- 가장 빈번하게 접속된 도메인
- 각 도메인의 요청 횟수
- 발생한 업/다운로드 트래픽
- 최근 접속 시간

요청 횟수 또는 트래픽 크기별로 정렬할 수 있어, 고빈도 접속 웹사이트를 식별하는 데 도움이 됩니다.

## 차단된 도메인 순위

![차단된 도메인 순위](/images/docs-feature-query-image-2.png)

차단 통계는 다음을 표시합니다:

- 차단된 도메인 목록
- 차단 횟수 통계
- 트리거된 필터 규칙
- 최근 차단 시간

목록에서 직접 다음 작업을 수행할 수 있습니다:

- 오탐된 도메인을 화이트리스트에 추가
- 차단을 유발한 구체적인 규칙 확인
- 통계 데이터를 내보내어 분석
