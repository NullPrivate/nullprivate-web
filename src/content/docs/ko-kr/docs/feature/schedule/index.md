## 기능 소개

AdGuard 개인 서비스는 유연한 인터넷 사용 시간 관리 기능을 제공하여 부모가 자녀의 온라인 시간을 더 잘 관리할 수 있도록 도와줍니다. 다양한 기기에 독립적인 인터넷 사용 규칙을 설정하여 가족이 건강하게 네트워크를 사용할 수 있도록 보장합니다.

## 설정 방법

1. AdGuard 개인 서비스 관리 인터페이스에 로그인
2. **필터** -> **차단된 서비스**로 이동
3. "인터넷 사용 시간" 옵션 클릭
4. 인터넷 허용 또는 차단 시간대 설정

## 사용 권장사항

- 학령기 아동에게 일과에 맞는 인터넷 사용 시간 설정
- 평일과 주말에 다른 정책 설정 가능
- 통일된 취침 시간 제한 설정 권장

![인터넷 사용 시간 설정](/images/docs-feature-schedule-_index.png)

## 주의사항

- 설정 변경 시 즉시 적용됨
- 시간대 설정은 언제든지 조정 가능
- 임시 제한 해제 기능 지원
