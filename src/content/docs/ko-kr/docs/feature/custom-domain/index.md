## 기능 소개

사용자 정의 해석을 통해 다음이 가능합니다:

- 로컬 네트워크 장치에 사용자 정의 도메인 이름 구성
- 개인 도메인 이름 해석 구현
- 내부 네트워크 서비스에 안전하고 편리하게 접근

## 적용 시나리오

### 네트워크 장치 접근

- NAS 장치: `nas.home → 192.168.1.100`
- 라우터: `router.home → 192.168.1.1`
- 프린터: `printer.home → 192.168.1.200`

### 개발 테스트 환경

- 로컬 서비스: `api.local → 127.0.0.1`
- 테스트 환경: `test.local → 192.168.1.50`
- 컨테이너: `redis.local → 172.17.0.2`

![NAS로 해석](/images/docs-feature-custom-domain-image-2.png)

## 구성 설명

### 기본 구문

```
도메인 이름 레코드 유형 대상 주소
home A 192.168.1.2
*.home A 192.168.1.2
```

### 지원되는 레코드 유형

- `A` 레코드: IPv4 주소 해석
- `AAAA` 레코드: IPv6 주소 해석
- `CNAME` 레코드: 도메인 이름 별칭

## 보안 기능

- 구성된 장치에서만 유효
- 내부 네트워크 IP 주소 유출 방지
- 와일드카드 도메인 이름 구성 지원
- 재시작 없이 실시간 적용

## 사용 권장 사항

1. 직관적인 도메인 이름 명명 선택
2. `.home`과 같은 접미사 사용 권장
3. 내부 네트워크 IP 변경 상황 기록
4. 정기적으로 해석 구성 확인
