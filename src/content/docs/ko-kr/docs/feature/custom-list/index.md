## 기능 개요

사용자 정의 차단 목록은 다음을 제공합니다:

- 정확한 도메인 차단 제어
- 유연한 규칙 가져오기/내보내기
- 실시간 적용 업데이트 메커니즘
- 편리한 목록 관리 인터페이스

## 지원하는 목록 형식

### 표준 형식

```
||example.com^
||ads.example.com^
```

### 주요 구독 소스

- AdGuard 형식
- HOSTS 형식
- Domain 형식

![사용자 정의 차단 목록](/images/docs-feature-custom-list-image.png)

## 시스템 사전 정의 목록

다음 최적화 목록을 제공합니다:

- **휴대폰 제조사 광고 차단**: 각 브랜드 휴대폰 시스템 광고 대상
- **일반 광고 차단**: 일반적인 광고 네트워크 커버리지
- **개인정보 보호**: 추적기 및 데이터 수집 차단

## 사용 권장 사항

1. **목록 선택**

   - 신뢰할 수 있는 출처에서 목록 추가
   - 중복 규칙 추가 피하기
   - 정기적으로 규칙 소스 업데이트

2. **성능 최적화**

   - 목록 수량 제어
   - 무효 규칙 제거
   - 차단 효과 모니터링

3. **문제 해결**

   - 차단 로그 기록
   - 규칙 구문 검증
   - 오차단 신속 처리
