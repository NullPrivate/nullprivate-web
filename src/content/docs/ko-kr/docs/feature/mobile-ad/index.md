## 문제 개요

많은 안드로이드 기기에는 출하 시 광고 소프트웨어가 사전 설치되어 있으며, 이는 다음과 같은 문제를 일으킵니다:

- 부적절한 시점에 광고를 팝업으로 표시
- 백그라운드에서 지속적으로 사용자 데이터 수집
- 시스템 자원을 차지하여 기기 성능 저하
- 불필요한 네트워크 트래픽 증가
- 배터리 지속 시간이 크게 단축

## AdGuard 솔루션

"닝핑(宁屏)"은 다음과 같은 방식으로 기기를 보호합니다:

- 광고 소프트웨어의 네트워크 요청 차단
- 악성 추적 행위 방지
- 기기 성능 최적화
- 배터리 사용 시간 연장
- 모바일 데이터 트래픽 감소
