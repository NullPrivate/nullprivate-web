## 빠른 시작

"닝핑"은 "열면 바로 사용"하는 디자인 개념을 채택했습니다:

- 사전 최적화 설정
- 지능형 규칙 관리
- 자동 업데이트 및 유지보수

## 설정 방법

### 암호화 연결 옵션

두 가지 안전한 암호화 방식을 제공합니다:

1. **TLS 암호화**

   - 더 높은 성능
   - 모바일 기기에 적합
   - DNS-over-TLS 지원

2. **HTTPS 암호화**
   - 더 넓은 호환성
   - 브라우저에 적합
   - DNS-over-HTTPS 지원

### 장치 설정 가이드

#### 브라우저 설정

- 링크: `https://xxxxxxxxxxxxxxxx.adguardprivate.com/dns-query/browser1`
- 모든 주요 브라우저 지원
- 추가 플러그인 불필요

#### 안드로이드 장치

- 서버: `android1.xxxxxxxxxxxxxxxx.adguardprivate.com`
- 시스템 수준 설정 지원
- 타사 DNS 앱과 호환

#### iOS 장치

- 전용 구성 파일 제공
- 시스템 수준 설정 지원
- 필요한 매개변수 자동 구성

## 고급 설정

### 사용자 정의 규칙

- 사용자 정의 필터 규칙 가져오기 지원
- 규칙 우선순위 설정 가능
- 정규 표현식 지원

### 성능 최적화

- DNS 캐시 설정
- 응답 시간 초과 구성
