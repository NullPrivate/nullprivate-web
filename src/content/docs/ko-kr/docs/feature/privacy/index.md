## 개인정보와 광고의 관계

광고주의 수익은 주로 광고 전환에서 발생합니다. 전환율을 높이기 위해 플랫폼은 다음이 필요합니다:

1. 사용자 유지율 향상
2. 맞춤형 광고 게재

이를 위해서는 대량의 개인정보 데이터 수집이 필요합니다. 플랫폼은 다음과 같은 방법으로 법적 제한을 회피합니다:

- 복잡한 이용약관
- 파트너사와의 데이터 교환
- 위장된 데이터 익명화

## 개인정보 보호 우선순위

개인정보 보호는 단순한 광고 제거보다 더 중요합니다:

- AdGuard 중국어 지역의 추적 차단 규칙(>40만 개)이 광고 규칙(<10만 개)보다 훨씬 많습니다.
- 일부 플랫폼은 광고는 적지만 개인정보 데이터를 통해 더 많은 수익을 얻습니다.

![개인정보 목록 항목 수](/images/docs-feature-privacy-image.png)

## 플랫폼의 "친절함" 이면

소위 맞춤형 추천은 실제로 사용자 요구를 이해하는 것이 아니라 플랫폼의 마케팅 전략인 경우가 많습니다:

- "당신이 이것을 좋아합니다"는 실제로 "내가 이것을 팔고 싶습니다"입니다.
- 친절해 보이는 서비스 이면에는 지속적인 데이터 수집이 있습니다.

## 자신을 보호하는 방법

"사이버 신중함"을 배우세요 — 개인정보 유출을 통제하고 플랫폼이 정확한 프로파일링을 하지 못하도록 하세요. AdGuard 개인 서비스는 이 목표를 달성하는 데 도움을 줄 수 있습니다.
