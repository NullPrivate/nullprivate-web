# 歡迎來到寧屏的世界 - 您的私人網絡安全衛士

**還在為無處不在的廣告、煩人的彈窗和潛在的私隱洩露而煩惱嗎？**

寧屏 (NullPrivate) 為您的所有聯網設備提供一道堅不可摧的數碼屏障。我們透過強大的加密 DNS 技術，在網絡請求的源頭就將廣告、追蹤器和惡意網站拒諸門外，還您一個清爽、高速、安全的互聯網。

---

## 🚀 為什麼選擇寧屏？

我們相信，每個人都應享有純淨且安全的網絡空間。

*   **廣告去無蹤**: 封鎖影片、網頁、App內的各類廣告，享受沉浸式內容。
*   **私隱更安全**: 阻止第三方追蹤器收集您的上網習慣，保護個人私隱。
*   **上網防病毒**: 自動攔截釣魚網站、惡意軟件和詐騙資訊，守護家庭網絡安全。
*   **設定超簡單**: 無需安裝任何軟件，在手機、電腦、路由器上原生設定即可，一勞永逸。
*   **全平台支援**: 無論是 Windows, macOS, iOS, Android 還是 Linux，我們都提供詳盡的圖文設定教學。
*   **家庭防沉迷**: 透過防沉迷功能，為孩子營造健康的網絡環境，防止過度沉迷。

---

## 核心功能

### 🛡️ 免費服務

所有用戶均可享受強大的基礎防護功能：

*   **公網存取**: 全面支援 IPv4 和 IPv6 網絡環境。
*   **廣告封鎖**: 攔截絕大多數廣告來源。
*   **私隱保護**: 封鎖已知的用戶行為追蹤器。
*   **安全防護**: 遠離釣魚和詐騙網站，尤其適合為家中長者設定。
*   **家庭保護**: 基礎的防沉迷功能，協助管理家庭網絡使用。

### ✨ 高級定制 (付費服務)

解鎖更多個人化與精細化管理功能：

*   **上網行為分析**: 查看您網絡中的設備存取了哪些網站，數據盡在掌握。
*   **防沉迷**: 一鍵封鎖成人內容和遊戲網站，為孩子營造健康的網絡環境。
*   **自訂規則**: 完全控制您的網絡，封鎖特定 App、網站或遊戲。
*   **內網穿透**: 自訂域名解析，輕鬆存取家中的 NAS 或伺服器。
*   **多設備管理**: 透過客戶端ID，區分並管理不同設備的上網策略與記錄。
*   **防沉迷設定**: 精細化的時間管理和內容過濾，防止孩子過度使用網絡。
