iOS 14或以上版本原生支援 Dns over HTTPS (DoH) 和 DNS over TLS (DoT) 加密 DNS，您可以透過以下方法開啟：

1.  打開內置瀏覽器 Safari，導航至私有服務後台，**設定指導** -> **DNS 私隱**
2.  **下載配置檔案**
3.  打開手機**設定**
4.  點擊**通用**
5.  點擊**VPN 和裝置管理**
6.  選取您的專用配置進行安裝
