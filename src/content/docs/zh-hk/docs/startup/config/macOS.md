macOS Big Sur 以上版本支援原生Dns over HTTPS(DoH)和DNS over TLS(DoT)加密DNS, 您可以透過以下方法開啟：

1.  打開自帶瀏覽器Safari, 導航到私有服務後台, **設定指導**->**DNS 私隱**
2.  **下載設定檔**
3.  打開**系統設定**
4.  打開**私隱與安全性**
5.  選中**描述檔**
6.  選中您的專用設定進行安裝
