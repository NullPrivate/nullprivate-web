## 什麼是釣魚網站？

釣魚網站是指偽裝成正規網站，以獲取用戶個人信息、賬號密碼等敏感信息的欺詐性網站。這些網站通常會模仿：

- 銀行和支付平台
- 社交網絡
- 電商網站
- 政府機構網站

## 主要危害

- 竊取用戶賬號和密碼
- 盜取銀行卡和支付信息
- 傳播惡意軟件
- 造成個人私隱洩露
- 導致財產損失
