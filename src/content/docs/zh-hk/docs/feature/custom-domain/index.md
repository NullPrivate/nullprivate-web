## 功能介紹

自訂解析允許您：

- 為區域網絡裝置配置自訂域名
- 實現私有域名解析
- 安全便捷地存取內網服務

## 應用場景

### 網絡裝置存取

- NAS裝置：`nas.home → 192.168.1.100`
- 路由器：`router.home → 192.168.1.1`
- 打印機：`printer.home → 192.168.1.200`

### 開發測試環境

- 本地服務：`api.local → 127.0.0.1`
- 測試環境：`test.local → 192.168.1.50`
- 容器：`redis.local → 172.17.0.2`

![解析到nas](/images/docs-feature-custom-domain-image-2.png)

## 配置說明

### 基本語法

```
域名 記錄類型 目標地址
home A 192.168.1.2
*.home A 192.168.1.2
```

### 記錄類型支援

- `A`記錄：IPv4地址解析
- `AAAA`記錄：IPv6地址解析
- `CNAME`記錄：域名別名

## 安全特性

- 僅在配置的裝置上生效
- 不會洩露內網IP地址
- 支援萬用字元域名配置
- 即時生效，無需重啟

## 使用建議

1. 選擇直觀的域名命名
2. 建議使用 `.home` 等後綴
3. 記錄內網IP變更情況
4. 定期檢查解析配置
