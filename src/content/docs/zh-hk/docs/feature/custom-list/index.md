## 功能概述

自訂攔截清單提供：

- 精確的域名攔截控制
- 靈活的規則導入導出
- 實時生效的更新機制
- 便捷的清單管理介面

## 支援的清單格式

### 標準格式

```
||example.com^
||ads.example.com^
```

### 主流訂閱源

- AdGuard 格式
- HOSTS 格式
- Domain 格式

![自訂攔截清單](/images/docs-feature-custom-list-image.png)

## 系統預設清單

我們提供以下優化清單：

- **手機廠商廣告攔截**: 專門針對各品牌手機系統廣告
- **通用廣告攔截**: 覆蓋常見廣告網絡
- **私隱保護**: 阻止追蹤器和數據收集

## 使用建議

1. **清單選擇**

   - 從可信來源添加清單
   - 避免添加重複規則
   - 定期更新規則源

2. **效能優化**

   - 控制清單數量
   - 移除無效規則
   - 監控攔截效果

3. **問題排查**

   - 記錄攔截日誌
   - 驗證規則語法
   - 及時處理誤攔截
