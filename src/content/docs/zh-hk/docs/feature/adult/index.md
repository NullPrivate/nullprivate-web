## 功能概述

"寧屏"採用多層次的內容過濾機制，可以有效識別和攔截：

- 色情和成人內容網站
- 暴力內容
- 賭博相關網站
- 其他不良資訊

## 工作原理

系統透過以下方式實現內容攔截：

1. **DNS層面攔截**: 阻斷已知不良網站的域名解析
2. **智能分類**: 基於多個可信數據源的分類系統
3. **實時更新**: 定期更新攔截規則，確保防護效果

## 配置指南

### 基礎設置

在過濾器黑名單中添加清單[Link](https://blocklistproject.github.io/Lists/adguard/porn-ags.txt)

### 高級選項

- **自定義規則**: 添加特定網站到攔截列表
- **例外管理**: 設置白名單，避免誤傷
- **訪問日誌**: 查看攔截記錄

## 應用場景

- **家庭保護**: 為未成年人創建安全的上網環境
- **企業管理**: 確保員工訪問符合工作要求的網站
- **公共場所**: 適用於圖書館、學校等公共網絡

## 注意事項

1. 建議與防沉迷功能配合使用
2. 定期檢查更新過濾規則
3. 如發現誤報，及時添加到白名單
4. 遇到繞過攔截的情況，可以提交反饋
