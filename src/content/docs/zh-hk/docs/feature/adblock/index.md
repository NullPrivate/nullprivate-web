## 廣告攔截的基本原理

"寧屏"採用DNS過濾技術，實時監控和分析網絡請求。當檢測到廣告相關的域名請求時，系統會自動返回空地址或本地環回地址，從而有效阻斷廣告內容的載入。這種方式既高效又對用戶透明，不會影響正常的瀏覽體驗。

## 智能黑名單系統

NullPrivate 採用多層次的黑名單管理機制：

- **自動更新**: 系統定期從可信源獲取最新的廣告域名列表
- **分類管理**: 按照廣告、追蹤器、惡意軟件等不同類別進行分類
- **性能優化**: 採用高效的匹配算法，確保快速響應
- **統計分析**: 提供詳細的攔截統計，讓您了解防護效果

## 靈活的白名單控制

白名單功能為您提供精確的訪問控制：

- **訪問保護**: 僅允許訪問受信任的網站
- **場景定制**: 適用於防沉迷和企業網絡管理
- **簡單配置**: 支援導入導出，便於管理
- **實時生效**: 修改即時生效，無需重啟服務

## 使用建議

1. 建議從基礎黑名單開始，逐步調整
2. 定期檢查攔截統計，了解系統效果
3. 遇到誤攔截時及時添加白名單
4. 針對特殊需求可以自定義過濾規則
