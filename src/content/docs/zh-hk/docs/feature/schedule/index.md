## 功能介紹

AdGuard私人服務提供靈活嘅上網時段管理功能，幫助家長更好地管理小朋友嘅上網時間。您可以為唔同嘅裝置設定獨立嘅上網規則，確保家人健康使用網絡。

## 設定方法

1. 登入AdGuard私人服務管理介面
2. 進入**過濾器**->**已封鎖嘅服務**
3. 點擊"上網時段"選項
4. 設定允許或禁止上網嘅時間段

## 使用建議

- 為學齡兒童設定符合作息嘅上網時間
- 可以針對工作日同週末設定唔同嘅策略
- 建議設定統一嘅就寢時間段限制

![設定上網時段](/images/docs-feature-schedule-_index.png)

## 注意事項

- 修改設定後會立即生效
- 可隨時調整時間段設定
- 支援臨時解除限制
