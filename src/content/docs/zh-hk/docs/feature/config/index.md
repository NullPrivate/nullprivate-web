## 快速入門

「寧屏」採用了「即開即用」的設計理念：

- 預設優化配置
- 智能規則管理
- 自動更新維護

## 配置方式

### 加密連接選項

提供兩種安全的加密方式：

1. **TLS 加密**
   - 更高效能
   - 適合流動裝置
   - 支援 DNS-over-TLS

2. **HTTPS 加密**
   - 更廣泛兼容
   - 適合瀏覽器
   - 支援 DNS-over-HTTPS

### 裝置配置指南

#### 瀏覽器配置

- 連結：`https://xxxxxxxxxxxxxxxx.adguardprivate.com/dns-query/browser1`
- 支援所有主流瀏覽器
- 無需額外插件

#### Android 裝置

- 伺服器：`android1.xxxxxxxxxxxxxxxx.adguardprivate.com`
- 支援系統級設定
- 兼容第三方 DNS 應用

#### iOS 裝置

- 提供專用配置檔案
- 支援系統級設定
- 自動配置所需參數

## 進階設定

### 自訂規則

- 支援匯入自訂過濾規則
- 可設定規則優先級
- 支援正則表達式

### 效能優化

- DNS 快取設定
- 回應逾時配置
