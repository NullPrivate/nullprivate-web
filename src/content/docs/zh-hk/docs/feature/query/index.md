## 完整的存取請求日誌

![請求日誌](/images/docs-feature-query-image.png)

存取請求日誌提供以下詳細資訊：

- 時間：請求發生的具體時間
- 用戶端：發起請求的裝置IP位址
- 請求目標：存取的網域名稱或IP位址
- 回應狀態：請求的處理結果
- 過濾規則：觸發的過濾規則（如有）

您可以使用搜尋框按網域、IP或規則名稱篩選日誌。日誌預設保留3天。

## 請求網域排行榜

![請求網域排行榜](/images/docs-feature-query-image-1.png)

網域存取統計展示：

- 存取最頻繁的網域
- 每個網域的請求次數
- 產生的上下行流量
- 最近存取時間

支援按請求次數或流量大小排序，幫助您識別高頻存取的網站。

## 被攔截網域排行榜

![攔截網域排行榜](/images/docs-feature-query-image-2.png)

攔截統計顯示：

- 被攔截的網域清單
- 攔截次數統計
- 觸發的過濾規則
- 最近攔截時間

您可以直接在清單中：

- 將誤攔截的網域加入白名單
- 查看導致攔截的具體規則
- 匯出統計數據進行分析
